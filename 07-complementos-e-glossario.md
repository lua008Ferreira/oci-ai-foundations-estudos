# 7. Complementos e glossário

## Ciclo de vida do ML
Definir o problema, coletar dados, preparar (limpar, tratar faltantes, normalizar, criar variáveis), treinar, validar e testar, implantar e monitorar.

Termos: **data drift** (os dados reais mudam e o modelo piora), **dados desbalanceados**, **data leakage** (informação do teste vaza para o treino), "lixo entra, lixo sai".

## IA responsável
| Princípio | Em uma frase |
|---|---|
| Justiça | O modelo não deve prejudicar grupos por viés |
| Transparência e explicabilidade | Dá para entender e justificar a decisão |
| Privacidade e segurança | Proteger dados pessoais (LGPD) e o modelo |
| Responsabilização | Alguém responde pelas decisões da IA |
| Supervisão humana | A decisão final sobre pessoas é humana |

## Vocabulário de PLN e visão
- **PLN:** tokenização, sentimento, entidades, classificação de texto, tradução, resumo.
- **Visão:** classificação (o que é), detecção de objetos (onde está), segmentação (pixel a pixel), OCR.
- **Fala:** ASR (voz para texto) e síntese de voz.

## Glossário
| Termo | Significado |
|---|---|
| IA / ML / DL | IA ⊃ ML ⊃ deep learning |
| Supervisionado | Com rótulo |
| Não supervisionado | Sem rótulo |
| Por reforço | Tentativa e erro com recompensa |
| Overfitting / Underfitting | Decorou o treino / vai mal até no treino |
| Recall / Precisão | Positivos reais achados / previstos que eram positivos |
| CNN / Transformer | Imagem / texto e LLMs |
| Token / Janela de contexto | Pedaço de texto / quantos cabem de uma vez |
| Temperature | Aleatoriedade da resposta |
| Zero-shot / few-shot | Sem exemplos / com exemplos no prompt |
| RAG | Busca dados externos e injeta no prompt, sem retreinar |
| Embedding / banco vetorial | Vetor de significado / guarda e busca por similaridade |
| Fine-tuning | Treina com dados próprios (LoRA, T-Few) |
| Alucinação | Resposta inventada e convincente |
| Language / Vision / Speech | Texto / imagem / voz |
| Document Understanding | Campos, tabelas e pares chave-valor |
| Data Science | Construir e implantar o próprio modelo |
